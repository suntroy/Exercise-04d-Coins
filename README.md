# Project 04 -- Jump Adventure
For this project, we were given C# scripts for a player character's motion with a camera following it, and expected to implemented a tile palette and visual scripting to create a platformer. I added music, sound effects, custom sprites, and level design to make the platformer my own.

## Implementation
Built using Unity 2022.3.45f
3 elaborate levels with differing paths to take
Different student-created enemy sprites for each level
Menu and level music
Sound effects for coin collection, diamond collection, enemy death, and flagpole reach
Main menu and menus between levels added
Score is reported via end of level menu
Interactable terrain via coins and diamonds
A user-controlled player that can jump and wall-jump, with a camera that follows
At least 6~ enemies per level
3 different enemy types (jumping, straight-path, charging)
